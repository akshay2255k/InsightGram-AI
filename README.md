# InsightGram AI

> AI Powered Instagram Relationship Intelligence Dashboard

InsightGram AI is a modern, privacy-first, AI-powered Instagram analytics dashboard that analyzes your official Instagram data export completely offline.

No login required.

No API required.

No cloud upload.

Your data never leaves your computer.

---

# Features

- Upload official Instagram ZIP export
- Find users who don't follow you back
- Find users you don't follow back
- Pending follow requests
- Recent follow requests
- Recently unfollowed profiles
- Close friends
- AI Relationship Score
- AI Recommendations
- Smart Relationship Insights
- Advanced Search
- Instant Filters
- Dashboard Analytics
- Beautiful Charts
- Local Database
- Export CSV
- Export PDF
- Export JSON
- Multiple ZIP Comparison
- Timeline History
- Notes
- Labels
- Favorites
- Keyboard Shortcuts
- PWA Support
- Desktop Ready
- Fully Offline

# Privacy

InsightGram AI never uploads your Instagram data.

Everything is processed locally inside your browser.

No server.

No tracking.

No analytics.

No advertisements.

# Getting Started

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Production build

```bash
npm run build
```

Preview

```bash
npm run preview
```
